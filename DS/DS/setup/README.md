# Acquisition Setup

APEX DS acquisition systems can be configured by invoking the Setup Editor
described in this Chapter. This editor contains multiple tabbed pages to
configure various aspects of the acquisition task. For simple cases only a  few
of these pages are displayed, but additional ones can be enabled as needed.

The Setup Editor is also used in other APEX DS suite applications, but only in
read-only mode. This allows users of these applications to inspect the
configuration of their data source.
