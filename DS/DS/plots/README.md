# Data Plots

The Data Plots components of the APEX DS user interface is a highly
configurable data  visualization tool. It supports multiple pages of plots in
various grid configurations. This component is available (potentially depending
on licensing) both on the main application window of APEX DS and also on up to
there secondary plot windows.
