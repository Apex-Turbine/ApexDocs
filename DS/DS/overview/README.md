# Overview

The APEX Data System suite is a family of interactive applications for high
speed and high channel count data acquisition and analysis tasks. These
applications are suitable for general purpose data acquisition projects, but
they also contain specialized features for rotating machinery testing. Members
of the suite include:

> - a data acquisition component, the **APEX Data System (APEX DS)**,
> - a data replay and visualization component, the **APEX Data Viewer (APEX DV)**,
> - a data monitoring user interface client, the **APEX Data Remote (APEX DR)**,
> - and various additional utilities.

The purpose of this Chapter is to give an overview of the APEX DS
architecture and to introduce the terms that will be used throughout this
Manual.
