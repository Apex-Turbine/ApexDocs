# Plot Creation Matrix

The table below contains a summary of the necessary data selections to create each of the supported data plot types
that will be described on the next sections.

| Plot | Plot Data | X Axis | Phase or Trigger | Notes |
| --- | --- | --- | --- | --- |
| Time | Channel(s) 1-N | N/A | N/A |  |
| Orbit | Channel(s) 1-N | 1 Channel | N/A |  |
| Scope (Continuous) | Channel(s) 1-N | N/A | N/A |  |
| Scope (Synchronous) | Channel(s) 1-N | N/A | 1 Speed Parameter |  |
| Scope (Triggered) | Channel(s) 1-N | N/A | 1 Speed Parameter |  |
| Magnitude | Channel(s) 1-N | N/A | N/A |  |
| Envelope | Channel(s) 1-N | N/A | N/A |  |
| Magnitude&Envelope | Channel(s) 1-N | N/A | N/A |  |
| Waterfall | 1 Channel | 1 Param or Stat | N/A | X Axis is optional |
| Campbell | Channel(s) 1-N | 1 Parameter | 1 Speed or Channel | X Axis and Phase optional |
| Z-Mod | 1 Channel | 1 Parameter | 1 Speed or Channel | X Axis and Phase optional |
| Tracking | Channel(s) 1-N | 1 Parameter | 1 Speed or Channel | X Axis and Phase optional |
| History | Param(s) or Stat(s) 1-N | 1 Param or Stat | N/A | X Axis is optional |
| Strip Chart | Channels(s) 1-N | N/A | N/A |  |
| Text Display | Param(s) or Stat(s) 1-N | N/A | N/A |  |
| Bar Display | Param(s) or Stat(s) 1-N | N/A | N/A |  |
| Gauge Display | 1 Param or Stat | N/A | N/A |  |
