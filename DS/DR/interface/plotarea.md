# Data Plots View

The Data Plots view of the APEX DS application's main window is a hightly
configurable data visualization tool. Users can create an arbitrary number of
plots on multiple pages. Each plot page can have a configurable plot grid
layout. In addition, the APEX DS application can display up to three additional
Data Plots view windows. These each have their own data plot configurations, and
can be used in an identical manner to the main window's view.

> [!NOTE]
> The Data Plots view is a separately licensed feature of the APEX DS
> application. Licenses for this feature are shared between all running
> instances of APEX DS and APEX DR. I.e. on a machine that has a single Data
> Plots View license, the user has a choice of using this license  in a DS or
> DR instance, but not in both.
